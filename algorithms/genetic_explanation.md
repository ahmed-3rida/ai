فكرتها مستوحاة من الطبيعة ونظرية التطور (البقاء للأصلح).

دعنا نشرح الكود خطوة بخطوة بطريقة مبسطة جداً:

### بناء الكلاس `GeneticKnightsTour`

```python
class GeneticKnightsTour:
```
- الكلاس هنا مثل "مصنع" يجمع كل خصائص وأدوات الخوارزمية الجينية.
- **في هذا النظام (Representation):** نحن نعتبر أن "الكروموسوم" (Chromosome) هو عبارة عن مسار محاولات الفارس. كلما طال المسار دون أن يعلق (أي دون أن يزور مربعاً مرتين)، كان هذا الكروموسوم أفضل وأقوى.

```python
    def __init__(self, n, start_x=0, start_y=0,
                 pop_size=200, generations=1000,
                 mutation_rate=0.15, elite_frac=0.1, tournament_k=5):
```
- دالة التهيئة `__init__` (المصنع من الداخل)، وتستقبل مجموعة إعدادات (Parameters):
  - `n`, `start_x`, `start_y`: حجم الرقعة ونقطة البداية.
  - `pop_size`: عدد الأفراد (المسارات) في كل جيل (مثلاً 200 مسار محتمل).
  - `generations`: عدد الأجيال التي سنسمح لها بالتكاثر والتطور قبل أن نتوقف (مثلاً 1000 جيل).
  - `mutation_rate`: نسبة حدوث طفرة عشوائية لتغيير مسار قديم (0.15 يعني 15%).
  - `elite_frac`: نسبة "الصفوة" أو أفضل الأفراد الذين سيتم نقلهم للجيل القادم مباشرة بدون تغيير لضمان عدم ضياع الحلول الممتازة.
  - `tournament_k`: عدد الأفراد الذين يتنافسون في "بطولة" لاختيار فرد للجيل الجديد. يتم تعيين هذه المتغيرات كخصائص للكلاس (`self.n = n` إلخ...).

### دالة بناء مسار عشوائي `random_tour`

```python
    def random_tour(self):
```
- وظيفتها إنتاج مسار عشوائي (فرد واحد) ليبدأ رحلته من نقطة البداية.

```python
        # ... إعداد المتغيرات والشبكة الفارغة ...
        for _ in range(n * n - 1):
            moves = valid_moves(x, y, n, visited)
            if not moves:

            moves.sort(key=lambda p: (degree(p[0], p[1], n, visited),

            x, y = moves[0]
            visited[x][y] = True
            path.append((x, y))

```
- تبدأ من نقطة البداية وتكرر القفزات.
- تجلب كل الحركات المتاحة `valid_moves`. إذا لم تجد حركات (انحبس الفارس)، توقف التكرار `break`.
- **السر العشوائي الموجه هنا:** ترتب الحركات بناءً على طريقة وارنسدورف `degree` كعامل أول (لنجعله ذكياً)، ولكن كعامل ثاني تضيف رقماً عشوائياً `random.random()`. هذا يجعل المسارات الناتجة تختلف عن بعضها البعض وتخلق "تنوعاً جينياً" في المجتمع.
- تختار الحركة الأولى (الأفضل والأكثر حظاً) وتضيفها للمسار ثم تعيد الكرة، وترجع المسار النهائي (سواء نجح أو وقف في المنتصف).

### دوال التقييم والاختيار (Fitness & Selection)

```python
    def fitness(self, path):
        return len(path)
```
- **التقييم (Fitness):** هذه الدالة تحسب قوة الفرد. قوتك هي ببساطة: "كم عدد المربعات التي استطعت زيارتها في هذا المسار؟". طول المسار الأكبر هو الأفضل (الهدف أن نصل إلى الطول `n*n`).

```python
    def tournament_select(self, population):
        sample = random.sample(population, min(self.tournament_k, len(population)))
        return max(sample, key=self.fitness)
```
- **البطولة (Tournament):** كيف نختار الأفراد لإنتاج الجيل القادم؟ لا نأخذ أفضلهم دائماً لكي لا تنحصر الحلول في زاوية واحدة، بل نأخذ مجموعة صغيرة عشوائية من المجتمع `sample` (مثلاً 5 أفراد)، ونأخذ الأفضل من هذه المجموعة الخمسة `max(... key=self.fitness)`. هذا يخلق توازناً بين الجودة والتنوع.

### دالة الطفرة `mutate`

```python

```
- **الطفرة (Mutation):** لا يمكننا دمج مسارين مختلفين للفارس في الشطرنج بسهولة (لأنه قد لا تكون نهاية المسار الأول متصلة ببداية المسار الثاني). لذلك الطفرة هنا عبارة عن "قص وإعادة بناء".

```python

        new_path = list(path[:cut])
```
- نختار نقطة قطع عشوائية في المسار الجيد الذي معنا. ونحتفظ بالمسار من بدايته حتى نقطة القطع (لأنه أثبت نجاحه حتى هذه النقطة).

```python
        # ... إعادة البناء ...
        for _ in range(n * n - cut):
            # ... نفس طريقة بناء مسار عشوائي ...
```
- من عند نقطة القطع، نجعل الفارس يحاول إيجاد طريق جديد لعلّ هذا التغيير البسيط ينقذه من المأزق الذي وقع فيه نهاية المسار القديم.

### الدالة الرئيسية للتشغيل `solve`

```python
    def solve(self, callback=None, stop_flag=None):
```
- هنا تبدأ دورة الحياة. تستقبل مُعطَيات اختيارية (`callback` لتحديث واجهة المستخدم بالرسم كل فترة، و `stop_flag` إذا أردنا إيقاف الخوارزمية يدوياً من زر في الواجهة).

```python
        population = [self.random_tour() for _ in range(self.pop_size)]
        best_path  = max(population, key=self.fitness)
```
- أولاً، ننشئ الجيل الأول: مجتمع عشوائي تماماً عدده `pop_size`. ونحدد من هو الفائز الأول حتى الآن `best_path`.

```python
        for gen in range(self.generations):
```
- حلقة التكرار تبدأ على عدد الأجيال المحددة (مثلاً من الجيل رقم 0 وحتى الجيل 999).

```python
            population.sort(key=self.fitness, reverse=True)
```
- في كل جيل، نرتب المجتمع من الأفضل (الأطول مساراً) إلى الأسوأ.

```python
            if self.fitness(best_path) == target:
                break   # perfect solution found
```
- نتحقق: هل وصل أفضل فرد لطول `n*n`؟ إذا نعم، ننهي البحث `break` فوراً لأننا وجدنا الحل!

```python
            # ── Build next generation ──
            new_pop = population[:self.elite_size]   # elitism
            while len(new_pop) < self.pop_size:
                p1    = self.tournament_select(population)
                child = self.mutate(p1)
                new_pop.append(child)
            population = new_pop
```
- **بناء الجيل الجديد:**
  - نأخذ أول مجموعة في الترتيب (الصفوة أو Elites) وننقلهم كما هم إلى الجيل الجديد `new_pop` لحفظ الجينات الجيدة.
  - حتى يمتلئ الجيل الجديد ليصبح عدده مكتملاً `pop_size`، نقوم بالآتي مراراً:
    1. نختار مساراً جيداً عن طريق البطولة `tournament_select`.
    2. نحدث فيه طفرة (قص وبناء جديد) `mutate`.
    3. نضيف المسار الجديد (الابن) للجيل الجديد.
  - أخيراً، نستبدل المجتمع القديم بالمجتمع الجديد `population = new_pop` وننتقل للجيل التالي.

```python
        elapsed = time.time() - t0
        success = self.fitness(best_path) == target
        return best_path, elapsed, success
```
