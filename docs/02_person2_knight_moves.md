## ♞ حركات الفارس

الفارس في الشطرنج يتحرك على شكل حرف **L**:
- خطوتان في اتجاه + خطوة في الاتجاه العمودي

```
  . X . X .
  X . . . X
  . . ♞ . .
  X . . . X
  . X . X .
```

### الحركات الـ 8

```python
MOVES = [
    ( 2,  1), ( 2, -1),   # نزول خطوتين
    (-2,  1), (-2, -1),   # صعود خطوتين
    ( 1,  2), ( 1, -2),   # نزول خطوة
    (-1,  2), (-1, -2),   # صعود خطوة
]
```

كل tuple هو `(delta_row, delta_col)`:
- `+` في row = نزول في اللوحة
- `+` في col = يمين
- `-` = الاتجاه المعاكس

## 🔍 دالة `valid_moves(x, y, n, visited)`

### وظيفتها
تُرجع قائمة بكل الحركات **القانونية والمتاحة** من موقع (x, y).

### شروط الحركة القانونية
```python
0 <= x + dx < n      # لا تخرج من الصف
0 <= y + dy < n      # لا تخرج من العمود
not visited[x+dx][y+dy]  # الخانة لم تُزَر بعد
```

### مثال
على لوحة 6×6، من الموقع (2, 2):
```
يُحسب: (2+2, 2+1) = (4, 3) ✅ داخل اللوحة وغير مزارة
        (2-2, 2-1) = (0, 1) ✅
        (2+1, 2+2) = (3, 4) ✅
        ... إلخ
```

## 📐 دالة `degree(x, y, n, visited)` — Warnsdorff's Heuristic

### وظيفتها
تُرجع **عدد الحركات المتاحة** من موقع معين.

```python
def degree(x, y, n, visited):
    return len(valid_moves(x, y, n, visited))
```

### لماذا نحتاجها؟ (Warnsdorff's Rule)
**الفكرة:** دائماً تحرك إلى الخانة التي لديها **أقل عدد** من الحركات المستقبلية المتاحة.

**المنطق:** الخانات الصعبة الوصول إليها يجب زيارتها أولاً، وإلا سنضطر للرجوع للوراء كثيراً.

```
درجة الحرية = 3 → اذهب إليها أخيراً (سهلة الوصول لاحقاً)
درجة الحرية = 1 → اذهب إليها أولاً! (ستُغلق قريباً)
```

## 🔗 كيف تُستخدم في بقية المشروع؟

# في backtracking.py (Person 3):

## ❓ أسئلة قد تُسأل عنها

**س: لماذا تحديداً 8 حركات؟**  
ج: لأن الفارس يستطيع التحرك في 4 اتجاهات للـ L (2+1)، وكل اتجاه له مرآة معاكسة = 8.

**س: ماذا يحدث لو كانت كل الحركات مشغولة؟**  
ج: `valid_moves()` تُرجع قائمة فارغة `[]` — وهذا يعني أن الفارس عالق.

**س: ما الفرق بين الـ `x` و `y` في الكود وفي الشطرنج؟**  
ج: في الكود `x` = رقم الصف (row)، `y` = رقم العمود (col). وهو العكس من الإحداثيات الرياضية المعتادة، لكنه شائع في مسائل الـ grid.

**س: ما معنى `heuristic`؟**  
ج: هو قاعدة ذكية تُقلل وقت البحث دون ضمان الحل المثالي في كل الحالات. Warnsdorff's تُقلل وقت Backtracking من ساعات إلى ثوانٍ على اللوحات الكبيرة.
